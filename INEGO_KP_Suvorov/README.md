# КП INEGO.dev для Суворова

Готовая сборка находится в папке `build`. Каждый HTML открывается в браузере с диска.

| Файл | Для чего |
| --- | --- |
| `KP_INEGO_Suvorov.html` | Внутренний редактор. Меняйте объекты, состав работ, цены и скидки. Чтобы отправить новое КП, нажмите «Сформировать КП», затем «Скачать КП для клиента». |
| `KP_INEGO_Suvorov_Client.html` | КП для клиента. Клиент выбирает работы и нажимает «Сформировать ответ» → «Скачать ответ». |
| `KP_INEGO_Suvorov_Reply_Example.html` | Демонстрационный HTML-ответ. В нём показаны выбранные и невыбранные работы, цены и итог со скидками. |

## Исходники

- `source/calculator.html` содержит разметку, стили, каталог работ, расчёты и логику обеих выгрузок.
- `source/offer.json` содержит данные текущего клиентского КП. Редактор использует их при первом открытии и затем сохраняет правки в браузере.
- `source/reference-visuals` и `source/fonts` содержат изображения, шрифты и лицензию. Сборка встраивает их в HTML.

## Пересборка

Установите Python, Node.js 18 или новее и зависимости Python. Запустите из корня этой папки:

```powershell
python -m pip install -r requirements.txt
python build.py
```

Скрипт пересобирает все три HTML-файла в папке `build` из исходников и данных в `source/offer.json`.
